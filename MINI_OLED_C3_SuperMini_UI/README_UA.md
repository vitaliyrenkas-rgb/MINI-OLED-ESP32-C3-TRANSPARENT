# Mini OLED v1.0.0 — прозорий HUD

Перша публічна апаратна версія компактної Bluetooth-колонки HU-009 з ESP32-C3 Super Mini та прозорим OLED SSD1309 128×64.

## Основне

- один постійний екран: час, дата, температура, вологість і погода;
- український інтерфейс;
- локальний Config Portal;
- NTP та OpenWeather;
- індикатори Wi-Fi і батареї;
- GPIO1 для вимірювання батареї через дільник 100 кΩ / 100 кΩ;
- блискавка всередині батареї з XOR-інверсією;
- кнопка GPIO9 → GND для повторного входу в портал;
- фінальне положення часу: `X=13`, baseline `Y=62`.

Детальне підключення, калібрування та фото наведені в основному `README.md`.
