# MINI OLEG — MINI-019 Clock Bottom Align

## Статус

Drop-in build для фізичного тесту на реальному ESP32-C3 Super Mini +
Waveshare 1.51" Transparent OLED.

**Код ще не проходив hardware test після цієї геометричної правки.**

## Що змінилось від MINI-018

- красива внутрішня XOR-блискавка в батареї залишена без змін;
- ширина Wi-Fi та батареї лишилась 9 px;
- час лишився на `x=13`;
- великі цифри часу більше не вирівнюються по верхньому краю з числом дати;
- нижній видимий край часу тепер прив’язаний до `y=62` — тієї самої нижньої
  лінії, по якій стоїть назва місяця і закінчується корпус батареї;
- після локального `setFontPosBottom()` режим позиціювання шрифту одразу
  повертається в `setFontPosBaseline()`, тому решта UI не змінюється;
- рядок `BUILD_VERSION` виправлено на `MINI-019-CLOCK-BOTTOM-ALIGN`.

## Актуальне підключення OLED

```text
OLED VCC -> 3V3
OLED GND -> GND
OLED DIN -> GPIO10
OLED CLK -> GPIO8
OLED CS  -> GPIO7
OLED DC  -> GPIO6
OLED RST -> GPIO5
BOOT     -> GPIO9
```

## Дільник батареї на GPIO1

```text
BAT+ ---- 100 kOhm ----+---- GPIO1 / ADC1_CH1
                       |
                    100 kOhm
                       |
                      GND

BAT-/HU-009 GND ------------- ESP32-C3 GND
```

Старий audio-sense на GPIO1 не використовується.

## Геометрія нижнього блоку

```text
Wi-Fi width:          9 px
battery width:        9 px
clock start:          x = 13
battery lower edge:   y = 62
clock lower edge:     y = 62
month lower line:     y = 62
```

## Перший фізичний тест

Перевірити на живому OLED три речі:

1. Чи низ `13:07` візуально стоїть на одній лінії з низом `липня`.
2. Чи не став час надто близько до горизонтальної лінії `y=31`.
3. Чи зберігся комфортний проміжок між батареєю та першою цифрою часу.

ADC-калібрування лишається таким самим, як у MINI-018.
